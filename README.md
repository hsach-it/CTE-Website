# High School CTE Pathways Website

## Overview
A website developed during my HSA IT Internship to showcase my high school's Career and Technical Education (CTE) programs. The website helps students explore 7+ career pathways and 33+ CTE classes, discover hands-on learning opportunities, and learn about programs that align with their interests and future career goals.

The goal is to create a modern, professional, accessible, and user-friendly experience that makes exploring CTE programs easy across desktop, tablet, and mobile devices.

## Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend/Database:** None, unless additional backend services are implemented

## Project Background
Developed during my HSA IT Internship, this project addresses a real-world school need by making career and technical education programs more accessible to students. The website brings together pathway information, course offerings, student learning experiences, and program news in one centralized location.

The project received positive feedback from school administration and is intended to provide students with a clear, engaging way to explore CTE opportunities.
